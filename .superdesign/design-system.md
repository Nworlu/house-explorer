# HomeView studio design system

HomeView is a calm, precise property-reconstruction tool for agents and developers. It should feel like a useful design workspace, not a marketing page.

- Use the existing off-white workspace `#f7f7f3`, white surfaces, deep green `#123f3c`, coral action `#ef5b54`, and ink `#172321`.
- Use the existing serif display face only for large section headings. Use the existing sans-serif for all editor UI and data.
- Keep controls compact, high-contrast, and clearly grouped by task. Inputs use single quiet borders; primary actions are coral and secondary actions are plain underlined text.
- Camera editing is a spatial task: show a live, framed preview alongside the numeric position controls; indicate the current camera direction, offer reset/open-full-preview actions, and retain a clear draft-versus-saved state.
- Avoid gradients, glass effects, decorative dashboards, and oversized icon cards.
